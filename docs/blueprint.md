# **App Name**: GrowthOS

## Core Features:

- Goal Tracking & Benchmarking: Compare current sales data and social media metrics against yearly goals stored in Firestore. Provide alerts and Course Correction plans if the user is off track.
- Personalized Content Ideation: Suggest high-fidelity, trending content ideas (e.g., Reels, TikToks) tailored to the user's niche. Use generative AI as a tool to craft hooks related to science for a Dermatologist or unique recipes for a bakery, to keep contents aligned with trend and user goals.
- Competitive Differentiation: Analyze how the user can differentiate from large competitors (Amazon, Temu) by highlighting their local/niche "intrinsic value". Focus on decentralized thinking.
- Sales Funnel Optimization: Ensure all suggestions directly impact sales. Each proposed content idea is filtered through the question: "Does this move the needle on sales?".
- Data Summary and Reporting: Synthesize data from the `goals` and `transactions` collections in Firestore to show a "Percentage to Goal" metric and provide actionable insights. 

## Style Guidelines:

- Primary color: HSL values (144, 70%, 40%), corresponding to hex code #3EB349, providing a balance of professionalism, health, and growth
- Background color: A lighter, desaturated shade of the primary hue at HSL (144, 20%, 90%), corresponding to hex code #E1F5E3, creates a calm and clean backdrop that enhances focus on the main elements
- Accent color: A contrasting color derived from an analogous hue (114, 90%, 45%) converted to hex code #41C99B is used sparingly to guide user interaction and highlight key metrics and actionable insights
- Font pairing: Use 'Space Grotesk' (sans-serif) for headlines to convey a tech-savvy feel, and 'Inter' (sans-serif) for body text, for a clean and readable interface. 
- Consistent use of clean, line-based icons related to business strategy, content creation, and data analysis.
- Dashboard layout: prioritize key metrics and goals. Implement a clean, card-based design for easy information access.
- Subtle transitions and animations to guide the user and provide feedback without being distracting.
